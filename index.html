A · Animation duration tests

8 tests

Each test selects one factory animation (Modes 2–9) exactly once, then watches without resending it. This is the cleanest way to estimate each natural animation duration and determine whether some modes are identical.

For separate recordings, use filenames such as CAL-M04.mp4. For the combined run, record continuously and use the screen's mode label to distinguish clips.

B · Bluetooth timing tests

7 tests

These tests deliberately compare repeated selections of the same mode with switching between Modes 4 and 7. Commands are issued at fixed planned offsets; actual send and completion timestamps are logged.

The final test requests 12 alternating commands at 50 ms intervals. It is a bounded stress test, not an accurate measurement of the radio's theoretical maximum throughput. Writes that remain pending are skipped rather than queued.

C · Mode numbering check

Optional

Tests the hypothesis that modes above 9 repeat earlier effects. Sends Mode 2, then Mode 10, with separate observation windows. Compare their visual patterns in the recording.
